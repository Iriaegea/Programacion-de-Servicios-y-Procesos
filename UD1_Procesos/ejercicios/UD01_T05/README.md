EJERCICIO 1:
    Hipótesis:

        Si participan más procesos, sería lógico que se tarde menos en terminar la tarea.
    

    Ejecución:

        Windows:
        Monoproceso: 0.01937039999756962
        Multiprocessing: 0.3446683999936795
    
    Identificación de problema:

       El monoproceso tarda menos a pesar de que sea un único proceso haciendo todas las tareas.

    Interpretación de resultados:
       
        Como es una tarea sencilla, el tiempo que consume crear los procesos y organizarlos hace que se tarde más que si participa un único proceso.
